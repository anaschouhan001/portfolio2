# Mohd Anas | Portfolio

Personal portfolio of **Mohd Anas**, a Data Analyst, Data Scientist and ML/AI Engineer.

**Live site:** https://anaschouhan001.github.io/portfolio2/

- Experience, projects, skills, education and a downloadable resume
- Dark theme by default, with a light-mode toggle
- Pure HTML/CSS/JS, hosted on GitHub Pages

Project cards are defined in `script.js`. Set a project's `live` field to a URL and a "Live Demo" button appears on its card.
